    How to use Calculas

    Input syntax

    • Powers: x^2, (1+x)^10
    • Functions: sin(x), cos(x), tan(x), log(x) (natural log), log2(x), log10(x), exp(x), sqrt(x), abs(x), asin(x), atan(x), sinh(x)…
    • Constants: e, pi, oo (infinity), I (imaginary unit)
    • Variables: x y z t plus parameters a b c n

    ODE input format

    For differential equations, write the equation in the form Eq(Derivative(y(x), x, n), rest), e.g.:

    • Simple: Eq(Derivative(y(x), x), y(x)) for y′ = y
    • Second order: Eq(Derivative(y(x), x, 2) + y(x), 0) for y″ + y = 0
    • Use D(y(x), x) shorthand: Eq(D(y(x), x), x*y(x))

    Vector fields

    For curl/divergence, enter each component in its own field, e.g. F = (−y, x, 0) → fields: -y, x, 0.

    Supported operations

    Derivatives, integrals (definite/improper/multiple), limits, Taylor series, ODEs, gradient, divergence, curl, Laplacian, Hessian, critical points, tangent lines, arc length, volumes/surfaces of revolution, residues, Fourier series, Laplace transforms and inverses.

    Keyboard shortcuts

    • Ctrl/Cmd + Enter — Solve current problem
    • Ctrl/Cmd + K — Focus expression input
    • Escape — Close modals/drawers
